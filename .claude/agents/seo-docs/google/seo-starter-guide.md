# Google SEO Starter Guide

**Source:** https://developers.google.com/search/docs/fundamentals/seo-starter-guide
**Last synced:** 2026-08-20

## Titles & meta descriptions

- Every page MUST have a unique `<title>` element
- Titles: 50–60 characters for desktop display (scannable in SERP)
- Format: `Page topic — Site/Business name` (or reversed for brand-focus)
- Meta descriptions: 150–160 characters, 1–2 sentence summary
- Each page requires distinct title and description — no templated repeats
- No keyword stuffing

## URL structure

- Use descriptive words in URLs — `/pets/cats` not `/2/6772756D`
- URL terms may appear as breadcrumbs in SERP
- Group topically similar pages in folders (`/policies/`, `/promotions/`)
- Minimize URL parameters where possible
- Ensure each piece of content is accessible through ONE canonical URL
- 301 redirect non-preferred URLs; if impossible, use `rel="canonical"`

## Heading hierarchy

- Use headings in logical sequence (H1 → H2 → H3)
- No penalty for disorder but improves accessibility
- No ideal count — use as many as needed
- Break long content into sections with clear headings

## Image optimization

- Alt text is critical: describe image-content relationship
- Good: `alt="Red yarn being held at a London yarn shop"`
- Bad: `alt="image"` or `alt="picture"`
- Place images near contextually relevant text
- Use high-resolution, optimized files

## Internal linking

- Link text must be descriptive — tells users AND search engines what's linked
- Bad: "click here" / "our products"
- Good: "charcuterie boards" / "return policy"
- Add `nofollow` to uncontrolled outbound links
- Auto-apply `nofollow` to all user-generated links (comments, forum posts)

## Video

- Standalone page with descriptive surrounding text
- Descriptive title (same rules as page titles)
- Complete video description field
- High-quality thumbnail

## Content fundamentals

- Unique — don't copy competitors
- Current — update and prune outdated material
- Readable — clear writing, proper grammar
- Helpful & reliable — expert/experienced sources
- Never stuff keywords (spam policy violation)

## Time-wasters (skip these)

- `<meta name="keywords">` — ignored by Google
- Keyword density targets or word count minimums
- Domain name keywords (minimal ranking impact)
- Subdomain vs subdirectory decisions based on SEO
- Obsessing over PageRank or perfect heading order
